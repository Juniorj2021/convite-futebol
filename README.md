# Convite Futebol

Página de convite e confirmação de presença para o futebol no Campo do Corujão.

## Publicação no Cloudflare Pages

- Repositório: `Juniorj2021/convite-futebol`
- Branch de produção: `main`
- Framework preset: `None`
- Build command: deixar vazio
- Build output directory: `public`
- Diretório de funções Pages: `functions/` (na raiz do repositório)

## Convex utilizado

O workflow de publicação do backend confirma que a chave `CONVEX_DEPLOY_KEY` deste repositório publica no deployment:

- Cloud URL: `https://grand-roadrunner-255.convex.cloud`
- HTTP Actions URL: `https://grand-roadrunner-255.convex.site`

Os proxies do Cloudflare Pages devem usar esse mesmo deployment. Não usar o endereço antigo `reminiscent-oyster-516`.
